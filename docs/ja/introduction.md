# イントロダクション

coverwise は組み合わせテスト生成エンジンです。モデルは、名前付きのパラメータ、それぞれが取りうる離散的な値のリスト、そしてどの組み合わせが正当かを表す任意の規則からなります。これを渡すと、任意の 2 パラメータ（あるいは 3 パラメータ、モデルが指定した数のパラメータ）の正当な組み合わせをすべて網羅する、小さなテストスイートが返ります。すでにあるスイートを測ることも、不足しているスイートに行を追加することもできます。テストケースの実行は行いません。パラメータが何を意味するかについても、coverwise は何も知りません。

## 課題

組み合わせごとに 1 行を持つスイートは、モデルが非現実的になるよりずっと手前で現実的でなくなります。3 種類の OS、4 種類のブラウザ、3 種類の画面サイズなら 3 × 4 × 3 = 36 テストケースで、ここに 3 値のロケールとネットワーク条件を足すと同じ計算で 324 になります。この増え方は[組み合わせテストとは](primer/what-is-combinatorial-testing.md)で展開しています。

その組み合わせから無作為に部分集合を取れば実行はできますが、何を網羅したかを述べられません。「代表的な」ケースを手で選ぶ作業は、パラメータに値が 1 つ増えるたびにやり直しになる判断です。

## カバリング配列とは

**カバリング配列**とは、任意の 2 パラメータから取った値のあらゆる組み合わせが、少なくとも 1 つのテストケースに現れるように選ばれたテストケースの集合です。ペアの水準では何も捨てていません。捨てているのはペアどうしの重複です。

| モデル | 組み合わせごとに 1 テスト | ペアワイズスイート |
|---|---|---|
| 3 OS、4 ブラウザ、3 画面サイズ | 36 テスト | 12 テスト |
| 上記に 3 値のパラメータを 2 つ追加 | 324 テスト | 19 テスト |
| 4 値のパラメータ 10 個 | 1,048,576 テスト | 38 テスト |
| 4 値のパラメータ 20 個 | 1,099,511,627,776 テスト | 44 テスト |

右列は同梱のジェネレータが既定のシードで生成した値です。ペアワイズスイートの下限は、最大のパラメータ 1 対の組み合わせ数で決まります。下 2 行なら 4 × 4 = 16 通りです。そこから先はパラメータを増やしても、総数が掛け算で増えるのではなく数行ずつ増えるだけです。

ペアワイズが既定値なのは、複数の分野の障害報告を調べた研究で、故障の大半が 1 個のパラメータ単独か 2 個の相互作用で引き起こされ、それ以上を要するものは次第に少なくなる、という傾向が報告されているからです。この根拠と、そこから言えないことは[組み合わせテストとは](primer/what-is-combinatorial-testing.md)で扱います。これは定理ではなく観測です。3 つの特定の値が同時に揃ったときだけ現れる故障は、ペアワイズスイートでは見つかりません。その場合に効くのが強度を上げるという手段です。t = 2 が取りこぼすものと、強度を上げる代償は[強度](primer/strength.md)で扱います。

## 3 つの操作

coverwise が提供する操作は 3 つで、これらは 1 つのループを構成します。

- **generate** はモデルからスイートを構築します。
- **analyze** は任意のスイートをモデルに照らして測定し、割合だけを返すのではなく、欠けている組み合わせを名指しします。
- **extend** は残す価値のあるスイート（手書きのものでも、以前の生成結果でも）を受け取り、渡された行はそのままの順序で保ったまま、隙間を埋める最小限の行を追加します。

ゼロから始まるプロジェクトはほとんどありません。すでにスイートがあり、analyze がそれを測り、extend が足し、もう一度 analyze が測ります。この流れは[不足を少しずつ埋める](use-cases/close-the-gaps-incrementally.md)で最初から最後まで追えます。

## 用語

### パラメータと値

**パラメータ**はテスト対象システムにおける変動の 1 次元です。各パラメータは有限個の**値**のリストを持ちます。

```json
{
  "parameters": [
    { "name": "os", "values": ["Windows", "macOS", "Linux"] },
    { "name": "browser", "values": ["Chrome", "Firefox", "Safari"] }
  ]
}
```

### 強度

**強度**（t）は、一度に何個のパラメータを考慮するかを表します。t = 2 では、すべてのパラメータ対から取った値のあらゆる組み合わせがスイートに含まれている必要があります。t = 3 なら 3 つ組が対象です。強度が表すのは網羅すべき組み合わせの大きさであって、テストケースの大きさではありません。テストケースは t がいくつであっても常に全パラメータに値を与えます。t を上げると網羅対象の組み合わせが増え、それに伴って行数も増えます。

### 制約

実際のシステムには、そもそも成立しない組み合わせがあります。**制約**はそれを表す真偽値の規則で、パラメータ名と値を使って書きます。

```
IF os = Windows THEN browser != Safari
```

制約は生成後のフィルタではなく構築中に適用されるため、違反するテストケースはそもそも作られません。言語仕様の全体は[制約構文](constraints.md)にあります。

### 必要タプル集合とカバレッジ

**タプル**とは、t 個のパラメータから 1 つずつ取った値の具体的な組み合わせです。t = 2 なら `os=Windows, browser=Chrome` が 1 つのタプルです。**必要タプル集合**は、正当なテストケースが取りえないものを制約が取り除いたあとに残る、スイートが含むべきタプルの全体です。**カバレッジ率**は、そのうち実際にスイートが含んでいる割合です。coverwise は全部を狙います。`maxTests` の上限などで届かなかった場合は、数値だけを返すのではなく、まだ欠けているタプルを報告します。この考え方は、手で確かめられる大きさのモデルを使って[タプルとカバレッジ](primer/tuples-and-coverage.md)で最後まで展開しています。

## coverwise がしないこと

- **テストを実行しません**。出力は値の割り当ての一覧です。各行を実行可能なテストケースに変えるのはテストフレームワークの仕事で、coverwise がフレームワークのファイルを読み書きすることはありません。
- **パラメータの意味を知りません**。coverwise にとって `os` も `browser` も単なる名前です。ブラウザを 1 つ書き忘れていること、2 つの値が実質同じものであること、生成された組み合わせが対象領域では無意味であることは、いずれも判定できません。それを伝えられるのは、書かれた制約だけです。
- **ペアワイズで十分かどうかは判断できません**。t の選択はテスト対象システムに対するリスク判断であり、呼び出し側に残ります。
- **最小のスイートは約束しません**。ジェネレータは貪欲法による構築です。まず完全なカバレッジを狙い、スイートの小ささはその次に置くため、理論下限よりいくらか多い行数に落ち着くのが通常です。実測値と下限の対比は[パフォーマンス](performance.md)に掲載しています。
- **状態を持ちません**。各呼び出しはモデルを受け取って結果を返すだけです。セッションもプロジェクトファイルもキャッシュもありません。

## coverwise が動く場所

| サーフェス | インストール | 備考 |
|---|---|---|
| Node.js | `npm install @libraz/coverwise` | Node.js 18 以上、ESM のみ |
| ブラウザ | ESM インポート | WebAssembly モジュールはエントリポイントが読み込みます |
| ピュア TypeScript | `@libraz/coverwise/pure` サブパス | WebAssembly を読み込めない実行環境向けの、同一 API |
| Python | `pip install coverwise` | Python 3.10 以上。Linux ホイールは glibc 2.28 以上、macOS ホイールは 14 以降の Apple Silicon |
| ネイティブ C++ | CMake、静的ライブラリ | C++17 |
| コマンドライン | `pip install coverwise`、リリースアーカイブ、ソースビルド | JSON 入力、JSON 出力 |

どのサーフェスも同じアルゴリズムで動き、同じ正当な入力とシードからは同じスイートを返します。どれを選ぶかは[サーフェスの選び方](choosing-a-surface.md)を、この保証が正確に何を指すかは[決定性](determinism.md)を参照してください。
