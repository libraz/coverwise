# 入門

入門は、組み合わせテストを使ったことがない開発者に向けて、その考え方を説明します。各ページは 1 つの考え方を平易な言葉で説明し、それが coverwise の API で何を決めているのかを述べ、実行できる短い例を示したうえで、さらに先を扱うリファレンスページへ引き継ぎます。

coverwise を使うのに必要なところまでを扱い、そこで止まります。カバリング配列の背景にある組み合わせ設計の理論、すなわち直交表、構成の下界、ある大きさのスイートが存在することの証明は範囲外です。生成されたスイートが最小であるとは、どのページでも主張しません。coverwise が法則ではなく既定値を選んでいる箇所では、そのどちらであるかを明示します。

## 4 つのページのつながり

各ページは、前のページが定義した用語を使います。

1. [組み合わせテストとは](what-is-combinatorial-testing.md) — 全組み合わせを試すことがなぜ選択肢にならないのか、そしてはるかに小さい集合がなぜ任意の標本ではないのか。
2. [タプルとカバレッジ](tuples-and-coverage.md) — カバリング配列が網羅する単位と、手で確かめられる大きさのモデルでの数え方。
3. [強度](strength.md) — カバレッジ単位の大きさを決める数 t、t=2 が試さずに残すもの、そして上げたときの代償。
4. [制約と必要タプル集合](constraints-and-the-universe.md) — 組み合わせを禁止すると、作られるものと要求されるものの両方がどう変わるか。

[タプルとカバレッジ](tuples-and-coverage.md)は後半 2 ページの前提です。後半 2 ページは互いに独立しているので、どちらから読んでもかまいません。用語はそのページで最初に出たところで説明するので、1 ページだけを開いても読み進められます。

## 各概念が決めていること

中央の列は、呼び出す側がその概念を必要とする理由そのものです。知らないことが語彙の欠落ではなく、誤った呼び出しになって現れる箇所を挙げています。

| 概念 | この API で決めていること | ページ |
|---|---|---|
| 全組み合わせ・カバリング配列 | 生成されたスイートが入力空間よりはるかに小さい理由と、その行数を何と読んでよく何と読んではいけないか | [組み合わせテストとは](what-is-combinatorial-testing.md) |
| タプル・カバレッジ単位 | `totalTuples` が何を数えているか。そしてその数がテストケース数ではない理由 | [タプルとカバレッジ](tuples-and-coverage.md) |
| カバレッジ率 | `coverage` と `coverageRatio` が何に対する割合か。1 未満の値が何を伝えているか | [タプルとカバレッジ](tuples-and-coverage.md) |
| 強度（t） | `strength` が何を決めるか。そして 1 つ上げることが小さな変更ではない理由 | [強度](strength.md) |
| 制約 | どの組み合わせが決して作られないか。`constraints` がカバレッジ率の分母をどう変えるか | [制約と必要タプル集合](constraints-and-the-universe.md) |
| 必要タプル集合 | あるタプルが `uncovered` に一度も現れないままスイートから欠けていられる理由 | [制約と必要タプル集合](constraints-and-the-universe.md) |

## 1 つのモデルに現れる語彙

入門が扱う内容は、すべて 1 つのオブジェクトのフィールドです。モデルはパラメータとその値、組み合わせを除外する制約、そしてカバレッジを測る強度を宣言します。

```json
{
  "parameters": [
    { "name": "os", "values": ["Windows", "macOS", "Linux"] },
    { "name": "browser", "values": ["Chrome", "Firefox", "Safari"] }
  ],
  "constraints": ["IF os = Windows THEN browser != Safari"],
  "strength": 2
}
```

`parameters` と `values` が入力空間を表します。`strength` はカバレッジ単位の大きさを固定します。`constraints` は、どの組み合わせが生成されないか、そしてどの組み合わせが要求されないかを決めます。各サーフェスはこのオブジェクトをそれぞれの書き方で表します。CLI なら JSON ファイル、JavaScript ならオブジェクトリテラル、Python ならキーワード引数です。意味はどれも同じです。
